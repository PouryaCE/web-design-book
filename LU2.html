01 آیا تا حالا اندیشیده‌اید؟

🤖
تا حالا به این فکر کردی که چطور میشه یه لیست از اعداد رو بدون تکرار ذخیره کرد؟ یا چطور میشه اطلاعات یه دانش‌آموز (نام، سن، نمره) رو طوری ذخیره کرد که سریع بهشون دسترسی داشته باشیم؟

پرسش‌های آغازین

  • اگر بخواهیم از مجموعه اعداد بدون تکرار استفاده کنیم، از ترتیب داده‌ها با حفظ کنیم و تغییر نپذیرد، از چه داده‌ای استفاده می‌کنید؟
  • فرض کنید می‌خواهید اطلاعات یک دانش‌آموز مثل نام، سن و نمرات او را ذخیره کنید و سریع به هر مورد دسترسی داشته باشید، چه ساختار داده‌ای مناسب است؟
  • اگر بخواهید یک عمل خاص را چند بار در برنامه استفاده کنید، بدون اینکه کد را تکرار کنید، چه راهی وجود دارد؟
  • چگونه می‌توانید در یک تابع تعدادی زیادی داده را پردازش کنید و عملیات تکراری را انجام دهید، بدون کد طولانی نوشتن؟
  • چگونه می‌توانید از کدهای آماده دیگران استفاده کنید؟ چه تفاوتی بین تابع و تابع دیگر وجود دارد؟

02 اهداف یادگیری پودمان

در پایان از هنرجو انتظار می‌رود:

  1. مجموعه‌ها و تاپل‌ها را تعریف کند، عناصر مجموعه‌ها را حذف یا اضافه کند و کاربرد هر یک را بداند.
  2. دیکشنری بسازد، کلید و مقدار اضافه کند، داده‌ها را با کلیدها بازیابی کند و کاربرد دیکشنری را در ذخیره‌سازی اطلاعات بداند.
  3. هنرجو قادر باشد توابع ساده بنویسد، پارامترها و آرگومان‌ها را استفاده کند و مقدار بازگشتی تابع را دریافت و به کار ببرد.
  4. هنرجو بتواند توابع پیچیده‌تری بنویسد، از حلقه‌ها در توابع استفاده کند و عملیات تکراری را در توابع مدیریت کند.
  5. ماژول‌ها را وارد کند، توابع و کلاس‌های آماده را در برنامه خود استفاده کند و ماژول‌های استاندارد پایتون را بشناسد.
  6. ماژول‌های محلی را ایجاد و استفاده کند.

04 مجموعه‌ها در پایتون (Sets)

🤖
اولین ساختار داده‌ی جدید، مجموعه (Set) هستش. تصور کن یه کیف داری که توش فقط وسایل متفاوت می‌ذاری و اصلاً ترتیب برات مهم نیست. این دقیقاً همون تعریف Set توی پایتونه!

مجموعه‌ها برای ذخیره چند مقدار در یک متغیر استفاده می‌شوند. مجموعه یکی از انواع داده پایتون است که برای ذخیره‌سازی انواع داده‌ها مثل اعداد صحیح، اعداد اعشاری، رشته‌ها، بولین‌ها و تاپل‌ها (tuple) به‌صورت مجموعه‌ای به کار می‌رود.

در پایتون، برای تعریف یک مجموعه از آکولاد {} استفاده می‌شود. مجموعه‌ها ترتیب ندارند و عناصر تکراری را حذف می‌کنند.

۰۱ مفهوم مجموعه و اشتراک (Set)
شکل ۱: اشتراک دو مجموعه (A ∩ B) شامل عناصری است که در هر دو مجموعه وجود دارند.
🛠️ ساخت set
create_set.py Python 
fruitset = {"apple", "banana", "cherry"}
print(fruitset)
{'banana', 'apple', 'cherry'}
نکته مهم

اگر برنامه‌ی بالا را چند بار اجرا کنید، متوجه می‌شوید که ترتیب نمایش عناصر تغییر می‌کند! این نشان می‌دهد Set ترتیب ندارد.

05 اضافه کردن به مجموعه (add)

برای اضافه کردن عنصر جدید به مجموعه، از متد add() استفاده می‌شود. برنامه را اجرا کنید، مشاهده خواهید کرد که عناصر تکراری به مجموعه اضافه نمی‌شوند.

add_to_set.py Python 
fruits = {"apple", "banana", "orange"}
fruits.add("grape")
fruits.add("grape")
print(fruits)
{'orange', 'grape', 'apple', 'banana'}

06 حذف از مجموعه (remove)

با استفاده از متد remove می‌توانید عنصر یک set را حذف کنید. اگر عنصری که می‌خواهید حذف کنید وجود نداشته باشد، برنامه خطا می‌دهد!

remove_from_set.py Python 
fruits = {"apple", "banana", "orange"}
fruits.remove("banana")
print(fruits)

# خطای زیر را اجرا کنید تا ببینید چه اتفاقی می‌افتد
fruits.remove("grape")
Traceback (most recent call last): File "remove_from_set.py", line 5, in <module> fruits.remove("grape") KeyError: 'grape'

07 بررسی وجود عنصر در set (in)

از عملگر in برای بررسی وجود یک عنصر در مجموعه استفاده می‌شود. اگر عنصر در مجموعه باشد True و در غیر این صورت False برمی‌گرداند.

check_set.py Python 
fruits = {"apple", "banana", "orange"}
if "grape" in fruits:
    print("grape is available")
else:
    print("grape is not available")
grape is not available
فعالیت: برنامه‌ای بنویسید که یک set از اعداد داشته باشد و بررسی کند عدد ۱۰ در set وجود دارد یا خیر.

08 دیکشنری (Dictionary)

🤖
حالا بریم سراغ دیکشنری! این ساختار داده خیلی شبیه دیکشنری واقعیه. یه کلمه (کلید) داری و معنی‌ش (مقدار) رو پیدا می‌کنی. توی پایتون هم به جای کلمه، یه «کلید» داریم و به جای معنی، یه «مقدار».

نوع داده dictionary شبیه دیکشنری لغات است که هر نام با یک شماره/لغت مرتبط است.

دیکشنری‌ها از تعدادی جفت کلید: مقدار (key:value) تشکیل شده‌اند که هر کلید به یک مقدار اشاره دارد. برای ایجاد dictionary آپشن‌ها درون آکولاد {} و با کاما از یکدیگر جدا می‌شوند.

۰۲ ساختار کلید-مقدار در دیکشنری
شکل ۲: در دیکشنری، هر کلید (Key) مانند یک برچسب عمل می‌کند و به یک مقدار (Value) متصل است.
create_dict.py Python 
person = {
    "name": "Arash",
    "age": 20,
    "city": "Tehran"
}

print(person["name"])
print(person["age"])
Arash 20

09 نکات مهم دیکشنری

اگر هر عنصر داری عنوان مشخص باشد (مانند نام دانش‌آموز و نمره او)، استفاده از دیکشنری بهتر از لیست است؛ زیرا در دیکشنری می‌توان مستقیماً با نام کلید به مقدار آن دسترسی داشت و نیازی به دانستن اندیس عنصر نیست.

کلیدهای تکراری

کلیدهای متفاوت می‌توانند مقادیر یکسان داشته باشند. اما اگر کلید در دیکشنری یک‌تا است، اگر همان کلید دوباره مقداردهی شود، مقدار جدید جای مقدار قبلی را می‌گیرد.

duplicate_keys.py Python 
car_dic = {
    "brand": "ford",
    "model": "mustang",
    "year": 1964,
    "year": 1920
}
print(car_dic)
{'brand': 'ford', 'model': 'mustang', 'year': 1920}
فعالیت: یک دیکشنری به نام book بسازید که اطلاعات یک کتاب را دارد: "title": "python Basic"، "author": "Fatemeh"، "pages": 250. نام نویسنده (author) و تعداد صفحات (pages) را چاپ کنید.

10 اضافه کردن آیتم جدید به دیکشنری

برای اضافه کردن یک عضو جدید به dictionary در پایتون، کافی است یک کلید جدید را مقداردهی کنید.

add_to_dict.py Python 
user = {
    "username": "ali",
    "age": 20
}
user["city"] = "Tehran"
print(user)
{'username': 'ali', 'age': 20, 'city': 'Tehran'}
فعالیت: یک دیکشنری خالی به نام student بسازید. سپس با استفاده از input از کاربر نام و نمره را بگیرید و در دیکشنری ذخیره کنید.

11 حذف عنصر از دیکشنری (del)

برای حذف یک کلید از دیکشنری از دستور del استفاده می‌شود. با این دستور، کلید و مقدار مربوط به آن به طور کامل از دیکشنری حذف می‌شود.

del_from_dict.py Python 
user = {
    "username": "ali",
    "age": 20,
    "city": "Tehran"
}
del user["age"]
print(user)
{'username': 'ali', 'city': 'Tehran'}
نکته امنیتی

در صورتی که قصد حذف کلیدی را دارید که در dictionary وجود ندارد، برنامه با خطا مواجه می‌شود؛ بنابراین قبل از حذف، باید وجود کلید بررسی شود. برای جلوگیری از خطا، از if "age" in user: استفاده کنید.

12 حذف عنصر از دیکشنری (pop)

برای حذف عنصر از dictionary می‌توانید از متد pop() نیز استفاده کنید. pop() عنصری که نام کلید مشخص شده را حذف می‌کند.

pop_from_dict.py Python 
product = {
    "name": "Laptop",
    "price": 1500,
    "stock": 10
}

# متد pop() علاوه بر حذف، مقدار حذف‌شده را برمی‌گرداند
price_value = product.pop("price")
print("Price removed:", price_value)
print(product)
Price removed: 1500 {'name': 'Laptop', 'stock': 10}
فعالیت: یک دیکشنری به نام inventory بسازید که شامل: "Bag": 5، "Ball": 8، "Laptop": 3، "Mouse": 10، "Flash memory": 14 باشد. وجود کالایی با نام "Bag" را بررسی و در صورت وجود، پیام مناسب چاپ کنید و سپس آن را با متد pop() حذف کنید و مقدار حذف‌شده را چاپ کنید.

13 متدهای پیشرفته دیکشنری

🤖
دیکشنری‌ها متدهای خیلی پرکاربردی دارن که کار باهاشون رو راحت‌تر می‌کنن. توی این بخش با get()، keys()، values() و items() آشنا می‌شیم.
🔍 متد get()

متد get() برای دسترسی به مقادیر دیکشنری استفاده می‌شود. مزیت اصلی آن این است که اگر کلید وجود نداشته باشد، برنامه خطا نمی‌دهد و مقدار پیش‌فرض (یا None) را برمی‌گرداند.

dict_get.py Python 
person = {"name": "Ali", "age": 20}

# دسترسی امن با get()
print(person.get("name"))  # Ali
print(person.get("city"))  # None (بدون خطا)
print(person.get("city", "Not Found")) # Not Found (مقدار پیش‌فرض)
Ali None Not Found
📜 پیمایش دیکشنری با keys، values و items

برای دیدن کلیدها از keys()، مقادیر از values() و هر دو (کلید و مقدار) از items() استفاده می‌شود. این متدها برای حلقه for فوق‌العاده هستند.

dict_loops.py Python 
scores = {"Math": 18, "Science": 15, "English": 20}

# فقط کلیدها
for key in scores.keys():
    print("Subject:", key)

# کلید و مقدار با هم (رایج‌ترین حالت)
for subject, score in scores.items():
    print(subject, ":", score)
Subject: Math Subject: Science Subject: English Math : 18 Science : 15 English : 20
فعالیت: یک دیکشنری از ۳ محصول و قیمت آن‌ها بسازید. با استفاده از items() نام و قیمت هر محصول را چاپ کنید.
آزمونک دیکشنری
کدام متد برای حذف یک عنصر از دیکشنری استفاده می‌شود و مقدار حذف‌شده را نیز برمی‌گرداند؟

B del

13 پروژه بازی Quiz

🤖
حالا وقتشه چیزهایی که یاد گرفتیم رو توی یک پروژه واقعی به کار ببریم! می‌خوایم یک بازی مسابقه‌ای (Quiz) بسازیم که سوال می‌پرسه و به جواب صحیح امتیاز می‌ده.

در این بازی ابتدا منویی که شامل انواع سوالات است نمایش داده می‌شود و کاربر سوال موردعلاقه‌اش را انتخاب می‌کند و سپس به سوالات پاسخ می‌دهد. در صورت پاسخ نادرست، پیام مناسبی نمایش داده می‌شود و پس از پاسخ سوالات، امتیاز کاربر نمایش داده می‌شود.

📝 مراحل ساخت پروژه

مرحله ۱: ابتدا منویی ایجاد کنید که شامل انواع سوالات باشد. برای شروع دو نوع سوال (ریاضی و جغرافیا) در نظر بگیرید.

مرحله ۲: سوالات مربوط به هر نوع سوال را بنویسید. از دیکشنری‌ها استفاده کنید.

quiz_game.py Python 
# ۱. منوی اصلی
menu = {
    "1": "Math Quiz",
    "2": "Geography Quiz",
    "3": "Exit"
}

# ۲. سوالات ریاضی و جغرافیا
math_quiz = {
    "2 + 2 = ?": "4",
    "5 * 3 = ?": "15",
    "10 - 7 = ?": "3"
}
geo_quiz = {
    "Capital of Iran?": "Tehran",
    "Capital of France?": "Paris",
    "Capital of Japan?": "Tokyo"
}

# ۳. نمایش منو و دریافت انتخاب
print("Welcome to Quiz Game!")
print("Menu:")
for key in menu:
    print(key, "-", menu[key])

choice = input("Select an option: ")

# ۴. اجرای کوییز بر اساس انتخاب
score = 0

if choice == "1":
    print("\nMath Quiz")
    for question in math_quiz:
        answer = input(question + " ")
        if answer == math_quiz[question]:
            print("Correct!")
            score += 1
        else:
            print("Wrong!")

elif choice == "2":
    print("\nGeography Quiz")
    for question in geo_quiz:
        answer = input(question + " ")
        if answer == geo_quiz[question]:
            print("Correct!")
            score += 1
        else:
            print("Wrong!")

elif choice == "3":
    print("Exiting the game...")
else:
    print("Invalid option")

# ۵. نمایش امتیاز
if choice in ["1", "2"]:
    print("\nYour final score is:", score)
Welcome to Quiz Game! Menu: 1 - Math Quiz 2 - Geography Quiz 3 - Exit Select an option: 1 Math Quiz 2 + 2 = ? 4 Correct! 5 * 3 = ? 15 Correct! 10 - 7 = ? 3 Correct! Your final score is: 3

14 تاپل (Tuple)

🤖
تاپل‌ها شبیه لیست‌ها هستن، اما یه تفاوت خیلی مهم دارن: تغییرناپذیرن! یعنی بعد از اینکه ساختیشون، دیگه نمی‌تونی عناصر داخلشون رو تغییر بدی. مثل یه سنگ حکاکی شده می‌مونن! 🗿

تاپل در پایتون دنباله‌ای از داده‌های ترتیبی و تغییر ناپذیر است. به کمک تاپل‌ها می‌توانید چندین مقدار از داده‌های مختلف را در یک متغیر ذخیره و روی آن‌ها عملیات انجام دهید. این ساختار داده را زمانی استفاده می‌کنیم که بخواهید داده‌ها در طول برنامه، تعداد ثابت خود شما و سایر برنامه‌نویسان هم تغییر نکنند.

شکل ۳: تاپل‌ها مانند یک جعبه قفل شده هستند؛ یک بار پر می‌شوند و دیگر تغییر نمی‌کنند.

توابع در برنامه‌نویسی، بلوک یا قطعه کدی است که یک‌بار آن را تعریف کرده و بارها آن را در چندین مکان برنامه می‌توان به صورت فراخوانی کرد.

مزایای استفاده از تابع:

  • برنامه‌نویس با تعریف یک تابع، تنها یک کار مورد نظر را می‌نویسد و سپس در هر نقطه‌ای از برنامه که نیاز به انجام آن کار باشد، آن را فراخوانی و استفاده می‌کند.
  • تقسیم کد به تکه‌های کوچک و مشخص، درک و فهم کد را به طور چشمگیری افزایش می‌دهد.
  • یافتن و رفع اشکالات و احتمال تغییرات در کد بسیار ساده‌تر می‌شود.
  • سازماندهی کدها به صورت منظم و مرتب و ساختار کلی برنامه آسان‌تر می‌شود.

19 پارامتر و آرگومان

پارامتر چیست؟ تابع می‌تواند ورودی‌هایی را دریافت کند. به ورودی‌های تابع در زمان تعریف تابع، پارامتر (parameter) گفته می‌شود.

آرگومان چیست؟ ورودی‌های تابع که هنگام فراخوانی تابع به آن داده می‌شود.

برای فراخوانی یک تابع، کافی است نام آن را نوشته و به تعداد پارامترها به آن آرگومان ارسال کنید (که در اصطلاح به آن «پاس دادن» می‌گویند). همچنین، یک تابع را می‌توان بارها فراخوانی کرد.

def show_product(name, price):

# فراخوانی تابع با ارسال آرگومان‌ها

show_product("Mobile", 3000000)
Product: Laptop Price: 5000000 Product: Mobile Price: 3000000
نکته مهم

تعداد و ترتیب آرگومان‌های ارسالی باید با تعداد و ترتیب پارامترهای تابع یکسان باشد. اگر تعداد آرگومان‌ها نادرست باشد، برنامه با خطا مواجه می‌شود.

24 آرگومان‌های نامحدود (*args و **kwargs)

🤖
فرض کن می‌خوای یه تابع بنویسی که هر تعداد عدد رو بگیره و جمع بزنه. نمی‌دونی کاربر ۲ تا می‌ده یا ۱۰ تا! اینجاست که آرگومان‌های نامحدود وارد عمل میشن.
🌟 کار با *args (آرگومان‌های متغیر)

اگر قبل از نام پارامتر یک ستاره (*) قرار دهید، پایتون تمام آرگومان‌های اضافی را به صورت یک تاپل (tuple) دریافت می‌کند. به این *args می‌گویند.

args_demo.py Python 
def sum_all(*numbers):
    print("Type:", type(numbers))
    print("Numbers:", numbers)
    return sum(numbers)

print("Total:", sum_all(5, 10, 15))
print("Total:", sum_all(1, 2))
Type: Numbers: (5, 10, 15) Total: 30 Type: Numbers: (1, 2) Total: 3
🔑 کار با **kwargs (آرگومان‌های کلیدی متغیر)

اگر قبل از نام پارامتر دو ستاره (**) قرار دهید، پایتون آرگومان‌های کلیدی اضافی را به صورت یک دیکشنری (dict) دریافت می‌کند. به این **kwargs می‌گویند. این برای توابعی که تنظیمات زیادی دارند عالی است.

kwargs_demo.py Python 
def create_profile(name, **info):
    print("Name:", name)
    for key, value in info.items():
        print(" -", key, ":", value)

create_profile("Ali", age=20, city="Tehran", job="Developer")
Name: Ali - age : 20 - city : Tehran - job : Developer

نکته طلایی این بخش

  • *args = تعداد نامحدودی آرگومان ترتیبی (به صورت تاپل)
  • **kwargs = تعداد نامحدودی آرگومان کلیدی (به صورت دیکشنری)
  • این ابزارها توابع شما را فوق‌العاده منعطف می‌کنند.

30 ماژول محلی (Local)

🤖
تا اینجا از ماژول‌های آماده پایتون استفاده کردیم. اما چطور میشه ماژول خودمون رو بسازیم؟ خیلی ساده است! کافیه یه فایل پایتون با پسوند .py بسازیم و توابعی که می‌خوایم رو توش بنویسیم.

ماژول‌های هزینه‌شده توسط برنامه‌نویس نوشته شده است و در برنامه import می‌شوند. اگر یک فایل پایتون با پسوند .py ایجاد کنید، می‌توانید توابع و متغیرها را در آن قرار داده و سپس آن‌ها را در برنامه اصلی خود import کنید.

📁 مثال ۱: ساخت و استفاده از ماژول ساده

ابتدا فایلی به نام my_module.py ایجاد کنید و کدهای زیر را در آن بنویسید:

my_module.py Python 
def greet(name):
    return "Hello, " + name + "!"

سپس در برنامه اصلی main.py کدهای زیر را بنویسید:

main.py Python 
# --- my_module.py ---
def greet(name):
    return "Hello, " + name + "!"

# --- main.py ---
import my_module
message = my_module.greet("Ali")
print(message)
Hello, Ali!

31 ماژول‌های شخص ثالث (Third-party)

این ماژول‌ها توسط توسعه‌دهندگان دیگر نوشته شده‌اند و برای استفاده از آن‌ها باید با استفاده از دستور pip install نصب شوند. سپس می‌توانید آن‌ها را در برنامه خود import کنید.

مثال‌هایی از این ماژول‌ها عبارتند از: Flask (برای ساخت وب)، PyGame (برای ساخت بازی) و Django (فریم‌ورک وب).

32 تفاوت تابع و متد

🤖
ممکنه برات سوال شده باشه که چرا گاهی از len(text) استفاده می‌کنیم و گاهی از text.upper()؟ این دو چه فرقی با هم دارن؟ توی این بخش، این تفاوت رو کامل یاد می‌گیری!

در مثال قبل، از دستوراتی مانند split()، upper() و append() استفاده کردیم، بدون آنکه تعریف‌شان را بدانیم. این نوع توابع، متد (Method) نامیده می‌شوند.

🧩 تابع (Function)

مجموعه‌ای از دستورات است که برای انجام کاری مشخص تعریف می‌شود و به صورت مستقل با استفاده از نام خود فراخوانی می‌شود.

مثال: شمارش تعداد کاراکترها: len(users)

function_example.py Python 
users = ["Arash", "Sara", "saba"]
print(len(users))
3
🔧 متد (Method)

نوعی تابع است که به یک کلاس یا شیء مشخص تعلق دارد و برای انجام عملیات روی داده‌های همان شیء استفاده می‌شود. متدها با استفاده از نقطه (.) فراخوانی می‌شوند.

مثال: متدهای upper و lower که حروف را به بزرگ یا کوچک تبدیل می‌کنند.

method_example.py Python 
your_text = input("enter you text")
print(your_text.upper())
print(your_text.lower())
enter you text: It is a test IT IS A TEST it is a test
method_vs_function.py Python 
text = "Python Programming"
words = text.split()  # متد

numbers = [1, 2, 3]
numbers.append(4)      # متد

length = len(text)      # تابع

print(words)
print(numbers)
print(length)
['Python', 'Programming'] [1, 2, 3, 4] 18
فعالیت: تابعی بنویسید که یک رشته را از ورودی دریافت کند و تعداد حروف بزرگ، کوچک و اعداد آن را نمایش دهد.

33 چالش پیدا کردن باگ (Debugging)

🤖
برنامه‌نویس‌های حرفه‌ای بیشتر وقتشون رو صرف پیدا کردن باگ (خطا) می‌کنن تا نوشتن کد! توی این چالش، من یک کد رو با ۳ خطا برات نوشتم. دکمه اجرا رو بزن، خطاها رو ببین و توی ادیتور اصلاحشون کن.

کد زیر قرار است مساحت یک مستطیل را محاسبه کند و به کاربر نشان دهد. اما ۳ باگ در آن وجود دارد که باعث می‌شود برنامه کرش کند. آیا می‌توانید آن‌ها را پیدا و اصلاح کنید؟

  • راهنمایی ۱: ورودی کاربر چه نوع داده‌ای است؟
  • راهنمایی ۲: آیا می‌توان یک رشته (String) و یک عدد (Integer) را با هم جمع کرد؟
  • راهنمایی ۳: آیا متغیرها به درستی به تابع پاس داده شده‌اند؟
fix_me.py Python 
# ۳ خطا در این کد وجود دارد! آن‌ها را پیدا و اصلاح کنید.

def calculate_area(width, height):
    area = width * height
    # باگ ۱: تلاش برای چاپ یک عدد با استفاده از الحاق رشته
    print("Area is: " + area)

# باگ ۲: input همیشه رشته برمی‌گرداند
w = input("Enter width: ")
h = 5

# باگ ۳: احتمالا نام متغیرها اشتباه پاس داده شده؟
calculate_area(w, width)
Enter width: 10 Traceback (most recent call last): File "fix_me.py", line 10, in calculate_area(w, width) NameError: name 'width' is not defined
راه‌حل نهایی: اگر موفق نشدی، این کد اصلاح‌شده را بررسی کن:

w = int(input("Enter width: "))
h = 5
print("Area is: " + str(area))
calculate_area(w, h)
